# 支持格式与科学决策

## 范围

本工具读取**测量汇总表**：一个 `[Data]` 标记、分隔表头和数据记录。它发现上传文件的实际表头，不假设 MPMS 各代软件具有固定列序。支持逗号/制表符发现及显式分隔符、编码覆盖。原始电压扫描 `.rw.dat` 是不同的分块格式，明确不支持；重命名的位置/电压扫描同样拒绝。AC 磁化率处理、原始扫描拟合及背景扣除属于其他工作流。

[来源](../sources.md)中的 Quantum Design 文件分别解释 SVSM 汇总列、DC 原始扫描格式和 DC-Scan/SQUID-VSM 两种互补测量。汇总列说明不保证每代软件的模式完全一致，因此实现记录实际表头、单位和有限数值数量。公开资料不构成“较新的 DC 列在所有情况下优先”的依据。

## 列发现

检查阶段保守识别 `Temperature`/`Sample Temperature`、`Magnetic Field`/`Field`、包含 `Moment` 单词的磁矩名称，以及磁矩误差名称。保留完整源表头；末尾圆括号或方括号内的文本作为单位报告。分类仅产生候选，不替代科学选择。非标准名称可用完整表头或列序号显式选择。重复完整表头需要用数字序号消歧。横轴和磁矩不能选同一列。

空白、非数字、NaN 和无穷值不变成零。短记录用空字段补齐，同时保留原字段数；超出表头的字段会阻止转换，要求先解决错位。空源记录不参与记录编号，其物理源行范围单独记录。带分隔符的引号字段和跨行注释均可追溯。计算使用有限 Python 浮点数；原始字符串保存在映射和 XLSX 源表。

## 单位与质量

只使用用户给出的样品质量。raw 原样保留选定磁矩数值，报告已知源单位或单位未指定。质量归一化支持 emu 与 A m²；单位覆盖是对源数值单位的显式确认，不是猜测换算。归一化结果为 emu/g。X 保留源单位，包括源数据为 Oe 的磁场。不推算密度、摩尔质量、抗磁修正或单原子因子。

## 曲线与顺序

目标范围模式下，`record_count` 统计全源，`curve_record_count` 统计选定范围（包括其中的缺失值），`outside_target_record_count` 统计范围外记录。范围外记录在 `source_rows.csv` 中标记为 `outside_target_ranges`，曲线 ID 和行号留空。所有曲线产物使用 manifest 中同一组 `segments`。

默认单段是一种整理方式，不宣称只存在一个物理实验。可用两端包含的源记录范围显式覆盖。每个非空源记录恰好出现一次，包括 X 或磁矩无效的记录。逐曲线 CSV 和 XLSX 保留采集顺序；`XY_Wide` 为每条曲线提供独立的 X/Y 对，较短曲线只在末尾补空。重复 X、反向扫描和重复设定点均保持。不进行重采样、插值、排序或合并。

记录编号从列标题后开始。`source_line_start`、`source_line_end` 是原始解码文件从 1 开始的物理行；跨行引号注释可使一条记录覆盖多行。`curve_row` 从第一行数值开始计数；`curve_csv_row` 包含 CSV 的一行标题。`raw_cells_json` 保存补齐前的解码字段。源 SHA-256 将映射绑定至上传文件的确切字节。

## 解释与质量

识别 ZFC/FC、升降温、磁滞支路或不同样品需要测量流程信息。精确方向变化没有内置容差，也不能确定这些身份。拟合误差、回归值和传输状态保留在源字段中；没有通用数值阈值或自动剔除。PNG 展示选定数据，不评判测量有效性。额外分析前应核对仪器流程和用户希望实施的修正。

## 产物与执行边界

上传字符串按 XLSX 文本写入，`=` 开头也保持文本。可执行 OGS 只包含受控曲线标识及安全标题，上传注释、任意标签和表头不进入代码。追溯 CSV 将原字段放入 JSON 数组。输出先在临时目录完成，全部产物成功后才移动成最终目录。

工作簿受 Excel 行数、列数和单元格文本长度限制；超出时停止，不截断。Origin 使用 CSV Data Connector，在独立工作簿/图中取第 1/2 列制图。版本兼容、缺失点连线和原生项目保存需要接收端验证。代码不调用本地 Origin MCP、COM 或桌面应用。
